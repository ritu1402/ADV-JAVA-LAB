## 🛠️ Technologies Used

- **Java** — Core programming language
- **Java Swing** — GUI-based application development
- **Java RMI** — Remote method invocation and distributed applications
- **Java Servlets** — Server-side Java programming
- **JSP** — Dynamic web pages
- **Apache Maven** — Project build and dependency management
- **Apache Tomcat** — Servlet and JSP application server
- **Git & GitHub** — Version control and project hosting

## 📌 Projects

### 1. Java Calculator — `ADJAVACALC`

A Java calculator project organized into separate classes for the model, view, controller, and application entry point.

**Concepts covered:**
- Java programming and object-oriented design
- Separation of application components
- GUI-based application structure

A web application built using Java Servlet and JSP technologies.

**Project contents:**
- `Main.java` — Java Servlet source code
- `student.jsp` — JSP page
- `result.jsp` — JSP page
- `pom.xml` — Maven project configuration

**Concepts covered:**
- Server-side Java development
- Servlet and JSP integration
- Maven-based project structure
- Web application deployment using a compatible servlet container
